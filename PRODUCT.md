# Dahlia

Native Rust/GPUI application developed alongside the separate Swift Ortensia release. Existing Swift app, release and data remain separate. One editable floating Markdown note with autosave is the first milestone. Reuse Markraft's MIT editor, not a new editor or a webview.

The brief fixes Classic to Apple's installed Stickies appearance, with exact border parity required. Border measurement is still blocked because permitted app screenshots omit the outer frame. Do not claim parity from the current provisional outline. Glass, collapsed strip, note management, archive/trash/restore, per-note controls and global defaults follow after the first milestone.

Target verified here: macOS Apple Silicon. No performance or universal platform claims.
