# Dahlia handoff

This private repository was renamed from `qoodeng/ortensia-rust` to `qoodeng/dahlia`, retaining its history. The existing Swift Ortensia release and storage live in a separate workspace and must remain untouched. The Rust app is now named Dahlia throughout: package and executable `dahlia`, bundle identifier `dev.qoodeng.dahlia` (`assets/Info.plist`), and data directory `~/Library/Application Support/Dahlia`, moved once from `ortensia-rust` on first launch (see README). The approved product name is **Dahlia**; the copper mark under `assets/brand/dahlia/` and `assets/brand/dahlia.icns` is a work-in-progress original vector design, not yet integrated into the app bundle or UI.

**Typing fix:** macOS `NSWindow.setStyleMask` replaced the GPUI editor's first responder. `src/macos_input.rs` now preserves and restores that responder when the style changes, and skips unchanged masks. `cargo test --locked` passes, including the native main-thread regression in `tests/macos_input.rs`; that regression fails against the original setter. A locally ad-hoc-signed build was checked with isolated notes: individual character keys save in Classic and Glass, collapse/expand preserves typing, and saved text reopens after app restart. Bullets and checked/unchecked boxes now use black through the host's editor marker color and were visually checked in both appearances. Clippy and formatting pass.

**Release work remains:** rebuild and notarize a corrected app/DMG, then verify click/type/save/reopen in Classic and Glass in that signed artifact before distributing it. The old 1.0.0 DMG still contains the typing bug; its historical release checks do not qualify the new source. The installed application has not been replaced.

The previous, notarized 1.0.0 app and DMG were built from functional commit `f82b4e7bb96f42446ab03e77cda7db52a82192d2`. Its delivered disk image is `build/ortensia-rust-1.0.0-f82b4e7-arm64.dmg`, SHA-256 `b71974839faa8141e33fec848952f139efffea6071a628658d1a933c2a0b159b`; the Library attachment is `libfile_3e1a80e8a23481918549af7f2fa451a3`. Apple accepted app submission `DA71B6DD-0F72-4FDB-95A0-AE6A203A84C2` and DMG submission `E9C39881-85AF-4600-8D2A-B65EF83D584D`. The built DMG is ignored by Git and remains local. Receipt and native-check evidence are in `evidence/`; their historical pass statements predate this user-reported blocker.

The app reuses pinned Markraft (`d2ff6779e6098add5a1c2d09a3e09f102e5ca628`) for editing rather than implementing an editor. `scripts/prepare.sh` prepares the reviewed upstream dependencies. Build with `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer cargo build --offline --locked --release -j2`. Do not touch the Swift repo or the user's existing notes.
